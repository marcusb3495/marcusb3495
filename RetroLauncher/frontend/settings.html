Platforms

"Browser Core" is the EmulatorJS core id used for the in-browser "Play in Browser" button. Common values: nes, snes, gb, gbc, gba, n64, nds, genesis, segaCD, sega32x, segaGG, segaMS, psx, atari2600, atari7800, lynx, pce, arcade. Leave blank to only allow launching via a native emulator on the server.

"ScreenScraper System ID" narrows metadata/box-art search results to this platform when using the ScreenScraper provider below. Find the numeric ID for your system at screenscraper.fr/systemesliste.php. Leave blank to search across all systems (works fine, just slightly less precise).

Metadata & Box Art

Whichever provider is selected is used first; if it isn't configured below, RetroLauncher automatically falls back to the other one if that's set up instead.

ScreenScraper

ScreenScraper has much stronger retro/arcade coverage than IGDB, but requires a developer account: request one from the ScreenScraper team via their developer forum (this isn't an instant self-serve signup). A personal ScreenScraper account (optional, below) is strongly recommended too - without one, anonymous API calls are throttled hard.

IGDB

Create a free Twitch developer app at dev.twitch.tv/console/apps to get a Client ID + Secret, then paste them below.
